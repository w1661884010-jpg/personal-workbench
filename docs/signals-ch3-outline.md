## 3. 每小节的内容要求（计划规定）

统一结构：**问题引入 → 定义与条件 → 推导或算例 → 要点 → 易错点 → 关联**；按需配公式卡；每小节至少一道分步例题与一道理解检验。

各节的硬性要求（来自计划，逐条落实）：

- **第一节**：线性 / 时不变 / 因果 / 无记忆 / BIBO 稳定 / 可逆逐项判断，并给出两个反例
  - `y[n]=n·x[n]`：线性、时变、无记忆、因果，但**非** BIBO 稳定（n 在无界整数上遍历）
  - `y[n]=x[n]²`：非线性、时不变、因果、无记忆，且 BIBO 稳定
- **第二节**：区分**零输入 / 零状态 / 全响应**；只有零状态关系才能无条件写 `Y=HX`；连续卷积、离散卷积、差分/微分方程、频响、ROC、因果稳定判据互相对照
  - 固定样例 `y[n]=x[n]+0.5y[n−1]`（初始静止）：阶跃响应 `2(1−0.5^(n+1))`，`h[n]=0.5^n u[n]`
  - 另设 `y[−1]=1` 验证零输入项 `0.5^(n+1)`
- **第三节**：区分系统辨识 `H=Y/X` 与逆滤波 `X=Y/H`；激励不足、频谱零点、噪声放大、因果稳定逆的条件
  - 反例 `H(z)=1−2z^{−1}`：原系统 FIR 稳定，但因果逆 `1/(1−2z^{−1})` **不稳定**；不能以"非零即可除"判断可实现性
- **第四节**：采样/量化/运算/输出链路；区分系数量化、舍入、饱和与回绕
  - 舍入量化 `Q(x)=Δ·round(x/Δ)`，无溢出时 `|Q(x)−x|≤Δ/2`
  - `Δ²/12` 只在均匀误差等假设下给出，**不能写成无条件噪声定律**
- **第五节**：独立可执行 MATLAB 脚本 + 工具箱清单；`filter` 递推、`conv` 核对零状态响应、`freqz` 显式频点、量化误差验证
  - 非零初值下 `filter` 的 `zi` 是**内部状态**，不直接等同于任意方程初值
