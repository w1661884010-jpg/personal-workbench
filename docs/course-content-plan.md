## 一、问题诊断：为什么"浅显、难以建立章节之间的联系"

实测（`courses.js`，站点唯一内容源，无生成器）：

| 指标 | 实测 |
| --- | --- |
| 课程 / 章 / 小节 | 3 / 25 / 132 |
| 正文总量 | **9,802 字 → 每小节 74 字** |
| 每小节均字（分课程） | 信号 82 ／ 数电 **61** ／ 模电 80 |
| 例题 | 27 道（25 章中 **24 章只有 1 道**） |
| 检验题 | 50 道（每章恰好 2 道） |
| 公式 | 49 处（约 1/3 小节有） |
| 跨章 / 跨课程联系字段 | **0**（无 `connections` / `links`） |
| 前置知识 | 每章 2–4 个**纯标签**，不可点击、不指向章节 |
| 动手实验 | 25 个（每章 1 个，已与工作台 `presetId` 打通） |

三条根因：

1. **小节 = 一句结论。** 74 字只能写下定义和结论，写不下"为什么需要它、成立条件是什么、数量级多大、和上一节是什么关系"。读者拿到的是名词表，不是能推理的结构。
2. **没有承接句。** 每小节独立成段，章与章之间没有"上一章解决了什么、本章为什么必须出现"的过渡，所以三章读下来仍是三块孤立文本。
3. **模型里没有"联系"的位置。** 数据结构中不存在描述章节关系的字段 —— 这不是写作问题，是模型缺字段。**必须先在数据模型里给联系一个落点**，否则无论正文写多长，章节之间仍然连不起来。

## 三、内容模型扩展

`circuit-source/lib/course-model.ts`：

```ts
// LearningSection 追加
detail?: readonly string[];      // 2–3 段展开：关键关系 / 算例 / 边界条件
points?: readonly string[];      // 3–5 条要点
pitfalls?: readonly string[];    // 1–3 条易混点 / 常见错误
links?: readonly { to: string; why: string }[];  // 本节与其它章节的关系

// ChapterDefinition 追加
connections?: readonly {
  to: string;                    // "<chapterId>" 或 "<chapterId>#<sectionId>"
  kind: "prereq" | "next" | "cross";
  why: string;                   // 一句话说明"为什么会有这条边"
}[];
sourceRef?: readonly string[];   // 材料出处，如「课件_第2章-频域分析.pdf」
```

已有字段保持不变：`objectives / prerequisites / sections[{title, importance, content, formula?, variables?}] / examples / experiments / check / summary / tags`，`ChapterDefinition.intro?: boolean`（批 0 已完成）。

字数统计口径：**`content` + `detail.join("")`** 计入正文；`points` / `pitfalls` 单独计数。

## 四、写作模板（每小节五段式）

| 段 | 落点 | 字数 | 要求 |
| --- | --- | --- | --- |
| ① 承接 + 定位 | `content` 首句 | 40–60 | 必须出现"上一节／前面／在…之后"，并说清本节解决什么问题 |
| ② 概念与定义 | `content` 其余 | 60–80 | 定义、符号、单位、成立前提 |
| ③ 关键关系 | `detail[0]` | 70–90 | 公式或判据的含义 + 适用条件 + 边界 |
| ④ 量级 / 最小算例 | `detail[1]` | 60–80 | 一个具体数字或能算完的小例 |
| ⑤ 易混点 | `pitfalls` | 40–60 | 与相邻概念的差别、常见错误 |

`points` 3–5 条，每条 15–30 字，是可背诵的结论；`links` 1–3 条，只在"这里真的用到别处"时写。

**样板（`signals-ch2-sampling` 采样、恢复与采样定理，示意）：**

> **content**：上一节把信号从时域推到频域，本节解决连续信号如何进入计算机：以等间隔时刻取样，把 x(t) 变成序列 x[n]。采样不是"取点近似"——它在频域把原频谱以采样频率为周期复制；只要复制件不重叠，原信号就能被理想低通滤波器无损还原。这就是采样定理的全部内容，也是后续 DFT、数字滤波得以成立的前提。
>
> **detail[0]**：设 x(t) 最高频率为 f_h，采样频率 f_s = 1/T。频谱复制后相邻副本间隔为 f_s，不重叠要求 f_s ≥ 2 f_h，临界值称奈奎斯特频率。f_s < 2 f_h 时高频分量落进低频位置形成混叠，且**不可逆**：数字结果无法唯一恢复原信号。
>
> **detail[1]**：音频取 f_h = 20 kHz，则 f_s 至少 40 kHz；工程取 44.1 kHz，把 4.1 kHz 余量留给抗混叠滤波器的过渡带。同一信号若用 f_s = 30 kHz 采样，15–20 kHz 分量会折叠到 10–15 kHz，听感上表现为刺耳的非自然噪声。
>
> **points**：① 采样的频域效果是频谱周期复制，不是取点近似；② f_s ≥ 2 f_h 是不重叠条件，工程留 10%–20% 余量；③ 抗混叠滤波器必须在采样**之前**，采样后的数字滤波救不回已折叠的分量；④ 恢复常用零阶保持或理想 sinc 插值，前者引入 sinc 包络失真。
>
> **pitfalls**：把 f_s ≥ 2 f_h 记成"采样率够高"而不查信号带宽——3 dB 带宽与含噪带宽会给出不同的 f_h；把混叠当成随机噪声——混叠是确定性折叠，改变采样率后位置会移动，可据此判别。
>
> **links**：→ `signals-ch2-frequency`「DTFT 的周期化正是采样在频域的体现」；→ `digital-08`「A/D 转换器是采样定理的硬件实现」。

**边界（重要）**：只做**本地重写**，不复制教材/课件原文；`sourceRef` 只记出处不引原文。材料中 `个人笔记/03_整理摘要/` 本身就是本地重写稿，可作为写作语气与深度的基准。

## 五、章节联系设计

三类边，全部由数据驱动、可点击：

- `prereq` 前置：读懂本章必须先掌握哪一章；
- `next` 后续：本章是哪些章的直接基础；
- `cross` 跨课程：与另两门课（或不在站点内的概率统计）的接口。

**信号与系统主线（来自材料 `03_整理摘要/00_个人笔记索引.md` 的总图，与教材章序一致）：**

```
绪论 → 连续信号 → 离散信号 → 信号处理基础 → 滤波器 → 随机信号
              ↘ 采样（连续↔离散的桥） ↗        ↘ 功率谱估计 ↗
```

| 章 | prereq | next | cross（示例） |
| --- | --- | --- | --- |
| 绪论 | — | 连续信号 | → 数电 1（离散与数制） |
| 连续信号 | 绪论 | 离散信号 | → 模电 4（频率响应／波特图） |
| 离散信号 | 连续信号 | 信号处理基础 | → 数电 8（A/D 是采样定理的硬件实现） |
| 信号处理基础 | 离散信号 | 滤波器 | → 模电 5（反馈与稳定性） |
| 滤波器 | 信号处理基础 | 随机信号 | → 模电 6（有源滤波）、模电 9（整流滤波） |
| 随机信号 | 滤波器 | — | → 概率统计（数字特征、相关性、抽样） |

数电、模电按同样方式各写一张骨架；`cross` 边至少覆盖：数电 3↔模电 1（门电路的电平与器件实现）、数电 8↔信号 2（采样与量化）、模电 6↔信号 4（有源滤波）、模电 9↔信号 4（电源滤波）。
