# 课程内容充实规划（2026-09-11）

目标：把站点课程正文从"一句话提纲"扩到可自学的正文，并在章节之间、课程之间建立**可点击的联系**；同时给内容质量加守卫测试，防止后续扩写退化。

## 一、现状（实测，来自 `courses.js`）

| 指标 | 现状 |
| --- | --- |
| 课程 / 章 / 小节 | 3 门 / 25 章 / 132 小节 |
| 正文总量 | **9,802 字 → 每小节平均 74 字**（基本一句话） |

数据模型（`circuit-source/lib/course-model.ts`）已有：`objectives / prerequisites / sections[{title, importance, content, formula?, variables?}] / examples[{title,prompt,steps,answer}] / experiments[...] / check[{prompt,options,answer,explanation}] / summary / tags`。

数据源：`courses.js` 由站点直接加载，README 已明确**当前没有课程生成器**，因此本文件就是课程内容的唯一来源，直接在树内扩写。

## 五、渲染改动（`app.js` + `styles.css`）

1. **课程导读只在绪论一次**（已完成）：`chapter.intro` 控制 `.lesson-guide`，无绪论章的课程由第一章承担；`.lesson-guide[hidden] { display: none }` 明确覆盖 `display: block`。
2. 章节页底部新增「**章节联系**」区块：渲染 `connections`，条目可点击跳转到目标章（复用 `jumpToChapter`），并标出 `前置 / 后续 / 跨课程`。
3. 小节内新增「要点」「易混点」折叠块（`details`），与正文同卡内呈现。
4. 「前置知识」由纯标签改为：能对应到章节的可点击跳转，不能对应的保持标签。
5. 可选（后置）：「学习路径」条 —— 按 `connections.prereq` 拓扑排序展示本课程主线。
