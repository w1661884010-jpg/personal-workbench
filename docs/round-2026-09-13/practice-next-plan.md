# 演练页下一阶段方案（本轮只记录，不实施）

## 目标：把"卷积验证"从**只看结果**升级为**看过程**

现状（实测）：
- 输入是 3 个 `type="number"` 文本框（w₁、w₂、dt），**没有滑块**；
- 只有 **1 个画布**，图例仅"─ 解析卷积 / ○ 数值卷积"，画的是 **y(t)**；
- τ 轴上的"翻转—平移—相乘—积分"过程完全没有呈现。

## 方案：双画板动态卷积演示仪

### 上画板（τ 积分轴——图解五步）

- 固定画出输入 x(τ)（矩形脉冲）。
- 动态画出翻转并平移后的 h(t−τ)，随时间 t 沿水平方向移动。
- 两者重叠相乘的区域用半透明高亮填充，并标注重叠区间的上下限 [a, b]。

### 下画板（t 结果轴）

- 画出 y(t) 曲线；
- 用与当前 t 绑定的垂直标尺 + 小圆点标出"此刻的输出值"——上画板阴影面积多大，下画板圆点就落在对应高度。

### 交互控制

- **时间 t 滑块**（核心控件）：范围从 −1 到 w₁+w₂+1；
- **▶ 播放 / ⏸ 暂停 / 单步步进**；
- 保留现有的**解析 vs 数值误差对照**（数值峰值、最大绝对误差、支撑区间）。

## 明确不做（本轮及下一阶段）

- **不加**指数信号、冲激信号预设。理由：冲激不是普通函数，**不能直接进普通采样求和**——现有数值分支是 `Σ rect(tₖ,w)·rect(t−tₖ,w)·dt` 的普通函数采样，对 δ(t−t₀) 必须走解析分支或广义函数处理；在没想清楚之前不引入。
