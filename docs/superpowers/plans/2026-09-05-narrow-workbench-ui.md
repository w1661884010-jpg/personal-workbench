# 2026-09-05 窄窗口工作台 UI 优化（阶段 A：滑块遮挡修复；阶段 B：窄屏布局整理）

范围：仅修改 3010 副本（`personal-workbench-shell-3010`）；3000 原站只作依赖来源，不改代码。
保留深灰配色、按钮风格、仿真逻辑、存档与学习状态。每阶段单独验证与提交；未经确认不推送、不部署。

修改前恢复标签：`restore-2026-09-05-before-narrow-workbench-ui`（HEAD e2a7df9）。

## 背景与根因（代码核对）

- `.kind-switcher` 桌面：`position: absolute; left:0; top:0; width:64px`（覆盖 901+ 网格 pad 列桩位）。
  `.kind-thumb`：`position:absolute; top:4px; left:4px; width:calc(100% - 8px); height:calc(50% - 4px)`，
  其包含块 = `.kind-switcher`（定位元素），滑块尺寸 56×36 正确。
- `@media (max-width: 820px)`：`.kind-switcher { position: static }` —— 切换器进入文档流并独占一行，
  但 `.kind-thumb` 仍是 absolute，包含块跳到最近的定位祖先 `.workbench-stage`（position:relative），
  thumb 变成“工作台宽 - 8px × 舞台高 50%”的巨型块 → 截图中的大块背景、覆盖工具栏与画布。
- `.limit-tip-button`（实验边界说明）同为 absolute `left:13px; top:80px`，≤820px 时参照 `.workbench-stage`，
  会压在切换器行下方/工作台卡片顶部，需检查遮挡。

## 阶段 A：修复巨型滑块遮挡（先保持竖向样式）

1. 真实浏览器在各视口（390/560/760/820/821/900/901/1440）复现并测量：切换器、thumb、参照祖先、
   工具栏/画布矩形；记录实际视口与 dpr。
2. 最小修复：≤820px 让 `.kind-switcher` 恢复定位参照（`position: relative`），thumb 重新相对切换器计算，
   尺寸回到 56×36；验证数字/模拟两种选中态 thumb 始终在轨道内、不覆盖工具栏/画布。
3. 实验边界说明图标 ≤820px 改为文档流（不做绝对定位），确认不遮挡切换器/工具栏/画布。
4. 不使用隐藏滑块、降低透明度、全局 overflow:hidden 或极端 z-index 掩盖。
5. 新增浏览器回归测试（先失败后通过）：定位边界（thumb ⊆ 轨道）、跨断点切换（760↔1440）、
   控件可点击性（elementFromPoint 命中 + 顶部工具栏在 thumb 之下不被遮挡）、两种选中态。

## 阶段 B：窄屏布局整理（≥901px 桌面布局不动）

1. ≤820px：数字/模拟切换器改横向紧凑分段控件（约 176×44，两项等宽），说明图标放其旁边（侧边流内，
   不绝对定位）；桌面保留竖向 64px 气泡。app.js 按方向写入 transform（窄屏 translateX(100%|0)，
   桌面 translateY），断点跨越时按当前选中态归位；aria-selected/tabindex 同步不变；
   不使用互相覆盖的内联 transform 与 !important。
2. 仿真操作：≤820px 自然换行（flex-wrap），启动类按钮（DOM 首位）优先；实验目标选择框单独一行，
   相关实验操作（载入预设/返回教材章节）紧随其后。
3. 存档区按用途分组（≤820px）：
   - 第一组：电路名称 + 保存电路 + 另存副本；
   - 第二组：本地电路选择 + 载入 + 删除；
   - 清空画布、删除本类存档保持低强调，与主要操作拉开间距。
4. 输入框可收缩列（minmax(0,1fr)+min-width:0），按钮不挤压成竖排文字（nowrap）；
   清除窄屏上残留的空列/空行/固定高度。
5. 不动仿真画布坐标、缩放逻辑与元件操作；需要滚动时只限对应区域，不撑宽页面。
6. 顶栏仅检查是否遮挡内容、高度计算是否正确，不做导航重构。
7. 验证：全视口（390/560/760/820/821/900/901/1440）逐项清单 + 新增回归测试（先失败后通过）+
   完整测试套件 + git diff --check；若改打包入口则重建 bundle 后测试。
