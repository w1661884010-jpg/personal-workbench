## 4. 内容要求

统一结构：**问题引入 → 定义与条件 → 推导或算例 → 要点 → 易错点 → 关联**；每小节至少一道分步例题与一道理解检验。

必须写清的关键点：

- **技术指标可检验**：通带/阻带边界、通带最大衰减 Ap、阻带最小衰减 As、过渡带宽度——不能用"去掉噪声"代替指标。
- **巴特沃思**：最大平坦、通带单调；阶数由 Ap、As 与频率比决定（给出公式与一个完整算例）。
- **切比雪夫**：允许通带纹波换取更陡过渡；ε 与 Ap 的关系；等波纹而非单调。
- **频率变换**：低通原型 → 高通/带通/带阻的映射，频率轴变换后指标如何跟着变。
- **IIR vs FIR**：IIR 用反馈、阶数低但需查极点稳定性且一般非线性相位；FIR 无反馈天然稳定、对称系数可严格线性相位，代价是阶数高。
- **两种设计法**：冲激响应不变法（有混叠）与双线性变换（无混叠但有频率扭曲，须预畸变）。
- **窗函数法**：主瓣宽度与旁瓣高度的折中；窗越平滑旁瓣越低但主瓣越宽。
