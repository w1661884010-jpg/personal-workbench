# 个人电子工作台

一个面向电子技术学习者的中文学习站点，把课程阅读、交互演练、基础电路搭建和错题复习放在一起。

**[点击打开在线站点 →](https://w1661884010-jpg.github.io/personal-workbench/)**

直接用浏览器访问即可，无需注册、安装软件或下载本仓库。电脑和手机均可使用；搭建较复杂的电路时，建议使用电脑或横屏查看。

## 可以用它做什么？

| 入口 | 用途 |
| --- | --- |
| 信号与系统 / 数字电子技术 / 模拟电子技术 | 按章节阅读知识内容、公式和例题，完成章节检验 |
| 顶部搜索框 | 查找课程、章节、知识讲解或实验，跳转到对应内容 |
| 演练 | 调整参数，观察信号波形和计算结果，结合实验步骤理解概念 |
| 工作台 | 在数字、模拟电路之间切换，查找元件、搭建电路并进行受支持的仿真 |
| 错题 | 复习章节检验中答错的题目，查看答案和解析，标记掌握情况 |
| 外观按钮 | 在跟随系统、暗色、亮色之间切换 |

## 第一次使用，建议这样开始

1. **选一门课。** 点击顶部科目，再从章节目录选择要学的内容。
2. **阅读并自测。** 看完章节后完成检验并提交；达到 60% 后可点击“标记本章已完成”。导学单元不计入完成进度。
3. **做一次演练。** 点击“演练”，选择一个实验。例如在“连续与离散信号观察”中改变频率或采样率，对照曲线与采样点的变化。
4. **回看错题。** 答错的章节检验题会自动收录到“错题”，可查看解析，再回到教材复习。

不用先熟悉所有功能；从一章内容、一次检验开始就可以。

## 如何搭建电路？

1. 点击“工作台”，选择“数字”或“模拟”。
2. 在元件搜索框输入中文名称或英文类型，例如“开关” / `switch`、“电阻” / `resistor`。
3. 点击元件即可放置；也可以在支持拖放的浏览器中拖到画布上。拖动画布中的元件调整位置。
4. 在“连线模式”下依次点击两个端口来连接；双击已有连线可删除它。
5. 双击元件选中后，可旋转、翻转、删除，或在“参数与状态”中修改参数。手机上部分编辑按钮会在选中后出现。
6. 使用数字台的“启动”，或模拟台的“求解 DC” / “启动瞬态”运行；结合探针、分析仪或示波器查看结果。
7. 想保留电路时，填写名称并点击“保存电路”。以后从“选择本地电路”中选择，再点击“载入”。

实验目标旁如果有“载入实验预设”，可以先载入再操作；并非每个实验都有预设。缩放按钮可以调整观察范围，画布会随窗口比例适配。

## 数据会保存在哪里？

本站没有账户系统，也不会把学习记录同步到云端。不同类型的数据保存方式不同：

| 数据 | 当前保存方式 |
| --- | --- |
| 章节答题、得分、完成状态 | 当前页面内存中；切换章节时保留，刷新或关闭页面后重置 |
| 错题与掌握状态 | 当前浏览器的本地存储 |
| 已点击“保存电路”的电路 | 当前浏览器的本地存储；未保存的草稿不要依赖刷新后保留 |
| 外观偏好 | 当前浏览器的本地存储 |

**请注意：** 换设备、换浏览器或换访问地址，不会自动带走记录。在线站点与 `localhost` 的数据也互不相通。清除网站数据、使用无痕模式或浏览器限制本地存储，都可能导致记录无法保留。不要把本站作为重要学习成果的唯一备份。

## 功能边界

- 这是学习辅助工具，不替代教材、教师指导、专业仿真软件或真实实验测量。
- 数字工作台支持基础组合与时序电路；模拟工作台主要用于线性直流、RC 瞬态等受支持场景。
- 模拟台中的二极管、三极管、运算放大器可用于搭建和连线，但当前没有可验证的非线性求解模型；能放置不代表能正确仿真。
- 请留意页面上的实验边界、诊断及不可求解提示；不要将演练或仿真结果直接作为实际硬件设计依据。

## 遇到问题或想提建议？

仓库目前尚未开放 Issues，也未设置公开反馈入口。遇到问题时，建议先保存以下信息，便于复现与排查：

- 所在页面、课程或实验名称；
- 从打开页面开始的复现步骤；
- 设备、浏览器，以及是否在微信等应用内打开；
- 截图或短录屏、期望效果与实际效果。

请不要上传密钥、账号信息或其他个人敏感数据。

## 本地运行与开发（普通使用者可以跳过）

### 只想在本地打开站点

安装 Node.js 后，在终端运行以下命令（发布流程使用 Node.js 22）：

```sh
git clone https://github.com/w1661884010-jpg/personal-workbench.git
cd personal-workbench
node serve.mjs 3010
```

然后打开 **http://localhost:3010/**。仓库已包含运行所需的打包文件，本地预览不需要先执行 `npm install`。建议通过本地服务器访问，而不是双击 HTML 文件。

### 修改源码之前，请先了解依赖

**能独立预览，不代表能独立重新构建全部源码。** 当前工作台、公式及课程数据的部分构建入口仍依赖同级 `personal-workbench-sites-3000` 项目的源码和 `node_modules`；只克隆本仓库无法直接完成这些重打包步骤。历史目录名 `3010` / `3000` 属于维护约定，普通在线使用不需要了解它们。

主要文件：

- `index.html`、`styles.css`、`app.js`：页面结构、样式和课程导航交互。
- `courses.js`：已打包的课程数据。
- `CircuitWorkbench.tsx`、`circuit-placement.ts`、`workbench-entry.tsx`：工作台源码与挂载入口。
- `workbench.bundle.js`、`workbench.bundle.css`：浏览器实际加载的工作台文件。
- `tests/`：测试；其中浏览器测试依赖本地 3010 服务、系统 Chrome 和测试文件指定的 Playwright 路径，不是开箱即用的跨机器测试环境。

```sh
# 具备同级项目与依赖后，重新打包工作台
node build-workbench.mjs

# 完整测试（需先满足上述测试环境要求）
node --test tests/*.test.mjs

# 校验并生成 GitHub Pages 静态发布目录
node build-pages.mjs
```

推送 `main` 后，GitHub Actions 会校验并发布已提交的运行文件。CI 的语法检查与静态资源校验不等于完整浏览器测试。`dist-pages/` 是生成目录，不是源码修改入口。

维护者需要恢复版本时，可查看 [恢复说明](docs/restore.md)。历史规划和迁移记录位于 `docs/superpowers/plans/`，不作为当前功能的使用指南。
