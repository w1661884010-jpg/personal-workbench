# 电路自习室

“电路自习室”是一个本地优先的本学期电子类课程个人学习站点，覆盖：

- 数字电子技术；
- 模拟电子技术；
- 信号与系统。

它把个人学习闭环收在一个站点里：查看今日任务 → 进入课程学习 → 阅读知识卡片 → 完成练习 → 记录错误 → 标记掌握状态 → 到期复习。

## 本地启动

环境要求：Node.js `>=22.13.0`。

在 `C:\Users\Lenovo\Documents\codex_projects\站点` 中执行：

```powershell
npm install
npm run dev
```

终端显示本地地址后，在浏览器打开：

```text
http://localhost:3000/
```

生产质量检查：

```powershell
npm test
npm run lint
npm run build
```

## 已实现的 V1

- Dashboard：本周进度、当前周次、三门课进度、今日主问题、最多三项任务、待复习知识点和明日第一件事；
- 课程总览：同一套三栏结构展示章节目录、路线、完成度、最近学习、薄弱知识点和待复习内容；
- 知识卡片：22 个指定章节均有问题、前置知识、核心概念、图示、公式变量、最小示例、常见错误、自测、学习证据和四级掌握状态；
- 练习与错题：按课程、章节、掌握状态筛选，支持新增、编辑和标记掌握；
- 课程连接：用五段流程说明信号与系统、模拟电子技术和数字电子技术的工程分工；
- 全局搜索：可搜索课程、章节、知识点标题、问题和标签；
- 本地同步统计：任务可勾选，掌握状态会立即更新课程进度与首页统计；
- 本地持久化：刷新后保留任务、掌握、证据、错题和复习日期；
- JSON 保护：支持完整导出，以及校验后覆盖导入；
- 响应式布局：桌面固定左导航与辅助栏，手机使用顶部工具栏和固定底部导航。

## 本地数据与 JSON 备份

站点不需要登录、服务器或数据库。学习状态保存在当前浏览器、当前站点来源的版本化 `localStorage` 中。

建议定期点击“导出 JSON”。导入时会先检查应用标识、schema 版本、课程引用和必需字段；无效文件不会覆盖现有记录。导入是完整覆盖，不是合并，因此确认覆盖前应先导出当前记录作为保险。

更换浏览器、切换访问域名、清除站点数据或使用隐私窗口时，本地记录不会自动迁移，需要手动导出和导入 JSON。

## V1 明确不做

- 账号、登录、服务器、数据库；
- AI 问答和自动生成课程；
- 云同步、社交、多用户协作；
- 复杂后台、资料库或真实硬件控制。

技术实现沿用仓库现有的 React 19 + TypeScript + Vite/Vinext 构建链，与 `.openai/hosting.json` 的 Sites 项目保持兼容。
