# 电路自习室 V3

“电路自习室”是一个本地优先的电子类课程个人学习站点，使用 React、TypeScript 和 Vite/Vinext。当前包含三个一级课程模块：

- 信号与系统：按本地赵光宙《信号分析与处理》第 3 版组织；
- 数字电子技术：按阎石《数字电子技术基础》第 6 版章序组织；
- 模拟电子技术：按童诗白《模拟电子技术基础》第 6 版章序组织。

课程内容按教材章节推进，不设置今日任务、连续打卡、学习天数或强制解锁。资料不足的章节和知识段会明确显示来源状态，不自行补写成既定课程内容。

## 学习流程

首页只显示三门课程的入口、当前学习章节和按章节计算的总体进度。进入课程后可以自由切换章节，未完成章节会保留原有状态。

每个章节页面固定采用以下七段顺序：

1. 学习目标
2. 前置知识
3. 知识讲解
4. 典型例题
5. 动手实验
6. 章节检验
7. 复习总结

知识讲解区分“主线必学”和“选择学习”，并显示本地资料的核对状态。实验会标注对应课程、教材章节、验证目标、操作步骤、预期证据和能力边界，并可在教材章节与相应工作台之间跳转。

## 章节进度规则

课程进度只根据计入进度的教材章节计算：

```text
课程进度 = 已完成章节数 / 计入进度的章节总数
```

章节状态为“未学习”“学习中”“已完成”。仅打开或阅读章节不会完成章节；必须先回答并提交本章全部检验题，随后“标记本章已完成”按钮才会启用。

章节检验分数用于反馈，不设置额外及格线。错题记录与章节进度相互独立：新增、编辑或标记错题已复盘都不会自动完成或取消完成章节。

## 电路工作台

数字电路工作台使用理想离散逻辑模型：

- 采用 `0 / 1 / X` 逻辑值；
- 支持组合逻辑和基础时序逻辑求值；
- 可切换开关电平、设置时钟频率；
- 提供 LED/数码管结果、逻辑探针、真值表和逻辑波形采样；
- 不模拟真实器件的电压阈值、传播延迟、驱动能力、竞争冒险或亚稳态。

模拟电路工作台当前只提供可验证的线性模型：

- DC 使用线性 MNA 求解；
- RC 瞬态使用固定步长后向欧拉积分；
- 支持线性电阻、电容、独立源、接地、电压表、电流表和节点探针；
- 二极管、BJT 和运算放大器可以放置、连线和保存，但当前没有求解模型；
- 电路中出现不支持的非线性器件时会停止求解并显示诊断，不生成替代电压、电流或波形。

因此，涉及二极管、晶体管、运放、整流、削顶、饱和或自激振荡的实验只提供拓扑核对或手算验证说明，不会用静态动画或伪造波形冒充仿真结果。

两个工作台都支持从空白画布放置、拖动、连接和删除元件，并提供：

- 保存电路到当前浏览器；
- 从本地电路列表载入；
- 复制为新的电路存档；
- 删除单个存档或全部本地存档；
- 清空画布；
- 查看实验目标并返回对应教材章节。

## 本地数据、迁移与备份

站点不需要登录、服务器或数据库。V3 学习状态保存在当前浏览器、当前站点来源的版本化 `localStorage` 中：

```text
personal-electronics-workbench:state:v3
```

电路存档也保存在浏览器本地，并在载入时校验文档版本和连接结构。刷新页面后，课程进度、章节检验、错题和电路存档会保留。

如果没有 V3 数据但检测到 V2 数据，站点会把原独立的“多级放大电路”记录映射到第六版第 3 章“集成运算放大电路”，并将合并后的章节设为“学习中”、清除旧检验提交，避免误标为完成。检测到更早的 V1 数据时，只把旧的当前知识点映射到对应课程章节，不推断完成状态。旧键不会被删除或覆盖，损坏或无法识别的数据不会作为有效学习状态载入。

页面提供学习记录的“导出 JSON”和“导入 JSON”。导入前会校验应用标识、schema 版本和章节引用；无效文件不会覆盖当前记录。导入是完整覆盖，不是合并，建议覆盖前先导出一次现有记录。

更换浏览器、切换访问域名、清除站点数据或使用隐私窗口时，本地记录不会自动迁移，需要手动导出和导入 JSON。

## 本地启动

环境要求：Node.js `>=22.13.0`。

在 PowerShell 中执行：

```powershell
cd C:\Users\Lenovo\Documents\codex_projects\personal-workbench-sites
npm install
npm run dev
```

开发服务器启动后，打开终端显示的本地地址。

构建并运行生产版本：

```powershell
npm run build
npm run start
```

构建 GitHub Pages 静态版本：

```powershell
npm run build:pages
```

静态产物输出到 `dist-pages`，资源基路径固定为 `/personal-workbench/`。推送到 GitHub `main` 后，`.github/workflows/pages.yml` 会运行测试、lint 和静态构建，再部署该目录。
